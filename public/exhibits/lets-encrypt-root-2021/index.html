The Root That Expired

2021-09-30 · a long tail on old devices

  1. 1An old root certificate reaches its long-announced expiry date
  2. 2Modern systems use the newer root and don't notice
  3. 3Old phones, old OpenSSL and embedded devices still trust only the old one
  4. 4TLS handshakes start failing on those clients
  5. 5Fixes range from config changes to buying new hardware ✕

An expiry date years away is still a date. Put it in a calendar.
